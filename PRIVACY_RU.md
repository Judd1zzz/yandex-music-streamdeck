# Политика конфиденциальности

**Интеграция с Яндекс Музыкой** (плагин для Stream Deck / StreamDock)

Последнее обновление: 06.10.2026

## Как плагин обрабатывает ваши данные

Плагин **не** передаёт никакой аналитики или телеметрии — ни мне, ни каким-либо аналитическим сервисам; третьи стороны участвуют только в необязательных функциях, перечисленных ниже. В нём отсутствуют трекеры и сторонние аналитические сервисы. Плагин хранит на вашем компьютере несколько файлов и устанавливает только перечисленные ниже сетевые подключения. Единственное подключение к стороннему сайту происходит, только если вы включите необязательный значок «Сгенерировано ИИ», по умолчанию выключенный.

## Что остаётся на вашем компьютере

- Настройки плагина (стили кнопок, настройки загрузки, если они доступны, настройки видеообложки и «Подробностей», а также включено ли управление с телефона) хранятся локально в хост-приложении Stream Deck / StreamDock.
- Статистика прослушивания (прослушанные треки, сессии, аптайм, загрузки, активность по часам и дням, топ артистов и треков, счётчики нажатий кнопок) хранится в файле `stats.json` в системном каталоге данных приложений: на macOS — `~/Library/Application Support/com.judd1.yandex_music/`, на Windows — `%APPDATA%\com.judd1.yandex_music\`. Версии до 2.5.0 держали этот файл в `logs/` внутри папки плагина; при первом запуске 2.5.0 один раз копирует его на новое место и переименовывает старый файл в `logs/stats.json.migrated`. Если установлены обе сборки (GitHub/StreamDock и Elgato), переносится статистика той, что запустится первой; старый файл другой остаётся в её папке `logs/`. Статистика никуда не отправляется.
- Лог плагина (`logs/plugin.log`) и сохранённый путь к клиенту «Яндекс Музыка» (`.ym_client_path`) остаются в папке плагина.
- Плагин не хранит токен Yandex Music. В сборках с функцией загрузки при скачивании трека плагин берёт токен из сессии запущенного клиента «Яндекс Музыка»; он используется только для запросов этого скачивания к API Yandex Music, и плагин его не сохраняет. Токен, введённый в прежних версиях, при первом запуске 2.5.0 стирается из глобальных настроек хост-приложения. В сборке из Elgato Marketplace скачивания нет, и токен не используется.

## Сетевые подключения, которые устанавливает плагин

- `api.music.yandex.net` — запросы к API «Яндекс Музыка», отправляемые от вашего имени (метаданные треков и загрузки в сборках, включающих функцию загрузки). В сборках с функцией загрузки сам аудиофайл скачивается по адресу хранилища «Яндекс Музыки», который возвращает этот API.
- `avatars.yandex.net` — обложки для кнопки «Информация о треке» и, в сборках с функцией загрузки, для тегов скачанного файла. Для Discord Rich Presence плагин передаёт в Discord адрес обложки, и Discord загружает её сам.
- Запросы, которые для функции «Подробности» делает сам клиент «Яндекс Музыка», — только пока включены «Дополнительные запросы к Яндекс Музыке» (по умолчанию включены): когда вы открываете страницу альбома, плейлиста или артиста, плагин просит клиент загрузить сведения этой страницы — по одному запросу на страницу, клиент отправляет его в «Яндекс Музыку» собственными средствами, ответ кэшируется на сеанс, третьи стороны не участвуют. Если выключить этот пункт, показывается только то, что клиент уже держит в памяти.
- `iimuzyka.top` — сторонний сайт, к которому плагин обращается **только если вы включите значок «Сгенерировано ИИ»** в «Подробностях» (по умолчанию выключен). Тогда для каждой открытой страницы артиста клиент отправляет ID этого артиста (число из адреса страницы) на `https://iimuzyka.top/`. В запросе нет cookie, данных аккаунта и реферера, но сайт видит ваш IP-адрес, как при любом запросе.
- Функция «Видеообложка» показывает фоновое видео, которое «Яндекс Музыка» даёт для текущего трека; клиент загружает его по адресу из данных трека, и плагин не добавляет к этому запросу никаких своих данных.
- «Управление этим компьютером с телефона» (по умолчанию выключено) — если его включить, плагин включает собственный режим клиента «Яндекс Музыка», в котором этот компьютер появляется как устройство в приложении Яндекс Музыки на телефоне. Сам плагин для этого никаких запросов не делает и токен не читает: клиент обменивается состоянием воспроизведения и командами с собственным сервисом «Яндекс Музыки» так же, как мобильное приложение. Если выключить, клиент заново загружает свои настройки из «Яндекс Музыки» и переподключается. Если же выйти из Stream Deck или удалить плагин, режим держится до перезапуска клиента.
- Связь с настольным приложением «Яндекс Музыка» идёт через подписанную библиотеку-мост плагина (`ym-bridge`): она загружается в клиент и открывает приватный локальный канал между плагином и клиентом. Порт отладки не открывается. Данные никогда не покидают ваш компьютер.
- `127.0.0.1` (localhost) — связь с хост-приложением Stream Deck. Данные никогда не покидают ваш компьютер.
- Discord Rich Presence (по умолчанию выключен) связывается с запущенным клиентом Discord по локальному IPC; затем Discord показывает в вашем профиле название трека, исполнителя и обложку — в этом и состоит функция.
- GitHub (`api.github.com` и загрузки релизов, на которые он указывает) — **только в сборках, распространяемых через GitHub/StreamDock**, для проверки наличия обновлений плагина и их скачивания. Сборка из Elgato Marketplace не содержит средства автоматического обновления; обновления предоставляются самим Marketplace.

## Ваша учётная запись

Вход в систему происходит исключительно в официальном приложении «Яндекс Музыка». Плагин никогда не видит и не запрашивает ваш пароль.
